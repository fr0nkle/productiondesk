Production Desk privacy

Production Desk stores scripts, breakdowns, schedules, shots, and settings locally on your device. Project content is not sent to Squid Productions or GitHub.

Update checks connect to the update host or GitHub to retrieve release metadata and downloads. These requests expose ordinary connection information, such as an IP address, to the hosting provider. Automatic update checks can be turned off in Production Desk → Updates.

This download page is hosted by GitHub Pages and requests the Mac update feed to offer the latest release. Windows downloads use GitHub Releases. There is no analytics or advertising code in Production Desk or this download page.

Bug and crash reports open a reviewable email draft. Crash summaries are stored locally and can be dismissed from the report form. Reports include your description and the technical details shown in the form; scripts, productions, original PDFs, and logs are not attached automatically. Only information you choose to send is emailed.

Project backups are files you choose to save or share. Reinstalling or upgrading the app preserves your locally saved projects.
